# 游戏配置

`js/游戏配置.js` 顾名思义，是游戏的配置文件，引擎运行时需要的一些基础信息都放在这里。大部分时候只改这个文件就够，不用动 `TTQ视觉小说引擎.js`。

打开这个文件，你会看到里面定义了若干个常量，最后统一挂到 `window.游戏配置` 上，引擎初始化时会读取。

## 章节文件列表

告诉引擎这个游戏有哪些章节、分别在哪里。

```javascript
const 章节文件列表 = [
    { 名称: "序章", 路径: "chapter/序章.dvns" },
];
```

- `名称` 是章节名，跳转的时候会用。
- `路径` 是章节文件的路径，支持 `.dvns` 和 `.js`。

我们想加一个新章节的时候，就在这个数组末尾加一行：

```javascript
{ 名称: "第一章", 路径: "chapter/第一章.dvns" }
```

具体怎么创建章节文件，可以看 [章节概念](../开始/章节概念)。

## 语言配置

控制游戏支持哪些语言、默认语言是哪个。

```javascript
const 语言配置 = {
    默认语言: 'zh',
    语言列表: { 'zh': '中文', 'en': 'English', 'ja': '日本語' },
    界面文字: { ... }
};
```

- `默认语言` 就是剧本原本的语言。
- `语言列表` 是游戏里可以切换的所有语言。
- `界面文字` 是界面按钮和提示的多语言对照。

想加一种语言，先在 `语言列表` 里加一项，比如：

```javascript
语言列表: { 'zh': '中文', 'en': 'English', 'ja': '日本語', 'ko': '한국어' },
```

然后到 `界面文字` 里，给每个条目补上对应语言的翻译。如果没写，界面上就会直接显示键名，比如 `快进`、`隐藏`。

## 立绘预设

给角色预设好立绘路径，剧本里就可以用角色名代替长路径。

```javascript
const 立绘预设 = {
    'Tian': 'aaa.png'
};
```

剧本里写 `@立绘 左, Tian` 时，引擎会去找 `aaa.png`。

我们也可以给同一个角色配多套预设，比如不同表情：

```javascript
const 立绘预设 = {
    'Tian': {
        '默认': 'assets/img/tian.png',
        '微笑': 'assets/img/tian_smile.png',
        '生气': 'assets/img/tian_angry.png'
    }
};
```

之后剧本里 `@立绘 左, Tian, 微笑`，就会用 `assets/img/tian_smile.png`。

## 角色样式表

给不同角色名配置名字的显示样式，比如让某个角色的名字是红色的。

```javascript
const 角色样式表 = {
    'Tian': {
        color: '#889900',
        fontStyle: 'italic'
    },
    'Dvnge': {
        color: '#d03838',
        fontWeight: 'bold'
    }
};
```

键是角色名，值就是 **CSS** 属性对象，只是换成在配置里统一管理。

## 初始状态

游戏一开始的默认状态。

```javascript
const 初始状态 = {
    当前章节: "",
    当前索引: 0,
    背景: "#222",
    背景媒体: { 循环: true, 播放次数: -1, 播放间隔: 0, 音量: 1 },
    标题: { 显示: false, 内容: "", 位置: "上", 样式: {} },
    头像: { 显示: false, 路径: "", 位置: "左" },
    左立绘: { 显示: false, 路径: "", 淡入: 500, 媒体: { ... } },
    中立绘: { 显示: false, 路径: "", 淡入: 500, 媒体: { ... } },
    右立绘: { 显示: false, 路径: "", 淡入: 500, 媒体: { ... } },
    音乐: null,
    用户变量: {},
    音乐淡出时间: 1000,
    音效: [],
    自动节点: 0,
    逐字显示: { 启用: true, 速度: 0.02 },
    快进模式: false,
    打字音效: { 启用: false, 路径: "", 音量: 1, 间隔字符数: 1 }
};
```

上面这些值都是游戏开始时的默认值。比如：

- 把 `背景` 的 `#222` 换成别的颜色，游戏开始时的背景就不一样。
- 把 `逐字显示.速度` 从 `0.02` 改成 `0.05`，默认打字速度就慢一些。
- 把 `音乐淡出时间` 从 `1000` 改成 `2000`，音乐切换的淡出就更长。

一般只需要改一两个自己关心的值，其余的不用管。

## 最大存档位

手动存档的数量。

```javascript
const 最大存档位 = 2;
```

改成 `4`，存档界面里就会显示 4 个手动存档位。改这里的同时，记得在 `game.html` 的存档列表里补上对应的 `.存档项`：

```html
<div class="存档项" data-slot="3" onclick="保存存档(3)"></div>
<div class="存档项" data-slot="4" onclick="保存存档(4)"></div>
```

## 历史记录配置

控制历史记录系统的行为。

```javascript
const 历史记录配置 = {
    启用: true,
    最大条数: 100,
    允许回退: true,
    回退后清除后续: true
};
```

- `启用`：是否开启历史记录，改成 `false`，就会关闭历史记录功能。
- `最大条数`：最多保留多少条历史。
- `允许回退`：玩家是否可以点击历史条目回退。
- `回退后清除后续`：回退到某一条时，是否清掉这条之后的历史。

如果只是想让玩家查看已读对话、不允许回退，可以这样设置：

```javascript
const 历史记录配置 = {
    启用: true,
    最大条数: 100,
    允许回退: false,
    回退后清除后续: false
};
```

## 限制游戏视口

控制游戏显示区域的大小，默认关闭，游戏会铺满整个窗口。

```javascript
const 限制游戏视口 = {
    启用: false,
    宽: '1280px',
    高: '720px'
};
```

如果我们想做一个固定分辨率的游戏，把它打开：

```javascript
const 限制游戏视口 = {
    启用: true,
    宽: '1280px',
    高: '720px'
};
```

游戏画面会被限制在 1280×720 的区域内，居中显示。

`宽` 和 `高` 支持多种写法：

- `'1280px'`：固定像素
- `'100%'`：百分比，相对父容器
- `'100vw'`、`'100vh'`：相对视口
- `'100dvh'`、`'100svh'`：支持各种 **CSS** 视口单位
- 直接写数字 `1280`：引擎会自动补 `px`

## 存储键名

统一管理存档、CG、变量等数据的存储键名。

```javascript
const 存储键名 = {
    语言: 'Dvnge_语言',
    CG: 'Dvnge_CG',
    用户变量: 'Dvnge_用户变量库',
    自动存档: 'Dvnge_自动存档',
    手动存档前缀: 'Dvnge_手动存档_',
    已选选项: 'Dvnge_已选选项'
};
```

一般情况下不用动。如果同一台设备上要跑多个 Dvnge 游戏，可以把这些键名都加个前缀区分开，比如 `游戏A_语言`、`游戏A_CG`，这样存档就不会互相覆盖。

## 导出配置

所有常量最后统一挂到 `window.游戏配置` 上：

```javascript
window.游戏配置 = {
    语言配置,
    存储键名,
    章节文件列表,
    角色样式表,
    立绘预设,
    初始状态,
    最大存档位,
    历史记录配置,
    限制游戏视口
};
```

如果你自己加了新的配置项，也在这里加进去，之后在剧本或自定义功能里就能通过 `读取配置('配置名')` 拿到。不过还是建议新建一个文件和引擎的区分开，方便更新引擎。
