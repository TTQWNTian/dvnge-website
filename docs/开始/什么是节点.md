# 什么是节点？

节点简单来讲就是“这一段话”（虽然不太严谨吧），在节点里面可以设置这里要有什么文本、立绘、背景等等，玩家每点击一下屏幕就会切换到下一个节点。

Dvnge 支持两种章节文件格式，`.dvns` 和 `.js`。两种格式的节点写法不同，但概念是一样的。

## dvns 里的节点

`.dvns` 文件由若干节点组成，节点之间用 `$` 分隔。

```dvns
"Tian": 你好，世界。$
```

上面就是一个节点。

再加一个节点：

```dvns
"Tian": 你好，世界。$
"Tian": 欢迎使用Dvnge~$
```

每个节点末尾都要加 `$`。

## js 里的节点

`.js` 文件用一个数组描述整章，数组里每个元素就是一个节点。

```javascript
var 示例 = [
    {
        角色: "Tian",
        内容: "你好，世界。"
    }
];
```

其中：

```javascript
{
    角色: "Tian",
    内容: "你好，世界。"
}
```

就是一个节点。

再加一个节点：

```javascript
var 示例 = [
    {
        角色: "Tian",
        内容: "你好，世界。"
    },// 注意：这里一定要加英文,号
    {
        角色: "Tian",
        内容: "欢迎使用Dvnge~"
    }
];
```

运行 `game.html` 再点击一下屏幕就能看到切换对话了。
