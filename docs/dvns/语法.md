# dvns 语法

本章介绍 Dvnge 的独创语法：**dvns**。

`.dvns` 放在 `chapter/` 目录下，一个文件就是一个章节。整份剧本由若干「节点」组成，节点之间用 `$` 分隔。

## 节点

一个节点就是一段对话加上它携带的所有指令。

```dvns
@背景 #fff
"Tian": 你好，世界。$
```

上面这段就是一个节点：

- `@背景 #fff` 设置背景
- `"Tian": 你好，世界。` 是对话

每个节点之间用 `$` 分隔：

```dvns
"Tian": 你好，世界。$
"Tian": 欢迎使用Dvnge~$
```

运行游戏，点击一下屏幕就切换到下一个节点。

::: warning 每个节点末尾必须加 `$` 。
:::

## 对话

格式是 `"角色名": 内容` 。

```dvns
"Tian": 你好，欢迎使用Dvnge。$
这是没有角色的旁白$
```

- 角色名显示在对话框左上角，可以留空。
- 内容支持任意 **HTML** 标签，比如 `<b>粗体</b>`、`<i>斜体</i>`、`<br>`，甚至`<button>按钮</button>`。
- 内容支持变量插值，用 `{变量名}` 引用用户变量。

```dvns
"Tian": 你好，{name}！你现在有 {金币} 块金币。$
```

变量不存在时会替换为“未知”，支持嵌套变量：

```dvns
"Tian": 当前血量 {玩家.血量}。$
```

如果想在对话里加特殊效果，也可以直接写 **HTML**：

```dvns
"Tian": <span style='color:red;'>今天的天气真好啊。</span>$
// 也可以使用 class
"Tian": <span class='highlight'>是适合使用Dvnge制作视觉小说的日子</span>$
```

## 指令

所有指令以 `@` 开头，参数之间用英文逗号 `,` 分隔，键值对用 `=` 连接。

```dvns
@指令名 参数1, 键1=值1, 键2=值2
```

## 背景

设置背景，支持纯色、图片、视频。

```dvns
@背景 #fff
@背景 assets/bg/room.png
@背景 assets/bg/opening.mp4
@背景 null
```

- `#fff`：纯色背景
- 带扩展名的路径：图片或视频背景
- `null`：清空背景为黑色

视频背景可以用 `@背景媒体` 控制播放：

```dvns
@背景 media/opening.mp4
@背景媒体 循环=true, 播放次数=1, 播放间隔=0, 音量=0.8
```

## 音乐

播放背景音乐，默认循环，切换时会淡出。

```dvns
@音乐 assets/bgm/theme.mp3
@音乐 assets/bgm/theme.mp3, 循环=true, 音量=0.7, 淡出=1000
@音乐 null
```

- `null`：停止当前音乐
- `淡出`：淡出时间，单位毫秒

## 音效

播放一次性音效，可以和音乐同时播放。

```dvns
@音效 assets/se/click.mp3
```

## 立绘

控制左、中、右三个位置的立绘。

```dvns
@立绘 左, assets/char/tian.png
@立绘 中, assets/char/tian.png, 淡入=500
@立绘 右, 角色名, 预设名
@立绘 左, false
```

- 第一个参数是位置：`左`、`中`、`右`
- 第二个参数是图片/视频路径，或角色名（配合预设）
- 第三个参数是预设名，可选
- `false`：隐藏该位置立绘

视频立绘可以用 `@立绘媒体` 控制播放：

```dvns
@立绘 中, media/char.mp4
@立绘媒体 中, 循环=true, 播放次数=1, 播放间隔=0, 音量=0.5
```

## 头像

显示在对话框左边或右边的头像。

```dvns
@头像 assets/avatar/tian.png
@头像 assets/avatar/tian.png, 位置=左
@头像 assets/avatar/tian.png, 位置=右
@头像 null
```

不写 `位置` 默认左，`null` 表示隐藏头像。

## 标题

在屏幕上显示标题文字。

```dvns
@标题 第一章
@标题 第一章, 位置=中
@标题 第一章, 位置=左上
@标题 第一章, 位置=中, 样式=color:#fff;font-size:48px
// 要使用class，这样写：
@标题 第一章, 位置=中, 样式=title-highlight
@标题 false
```

位置支持：`上`、`下`、`左`、`右`、`左上`、`左下`、`右上`、`右下`、`中`。

## 设置变量

设置用户变量。格式是 `"变量名"` 值，多个变量用逗号分隔。

```dvns
@设置变量 "好感" +1, "金币" 100
```

值支持：

- 数字：100、3.14
- 字符串：不用加引号直接写
- 运算：+1、-1、*2、/2，表示在当前值上运算

```dvns
@设置变量 "好感" +1
@设置变量 "金币" -50
@设置变量 "等级" *2
@设置变量 "血量" /2
```

嵌套变量用 `.`：

```dvns
@设置变量 "进度.第一章" 1
```

## 读档时设置变量

只在读档时应用，用于根据存档状态做特殊处理。

```dvns
@读档时设置变量 "回档" true
```

## 输入

显示输入框，玩家输入存入用户变量。

```dvns
@输入 name
@输入 name, 占位符=请输入, 提示文字=你的名字, 按钮文字=确认, 最大长度=20, 必填=true
```

- 第一个参数是变量名，必填
- `占位符`：输入框内灰字提示
- `提示文字`：输入框上方文字
- `按钮文字`：确认按钮文字
- `最大长度`：数字
- `必填`：`true` 或 `false`

翻译文件里可以省略变量名：

```dvns
@输入 占位符=Enter here,提示文字=Enter your name,按钮文字=Confirm
```

## 选项

分支选项。单独一行写 `@选项`，之后每一行是一个选项。

```dvns
@选项
是 -> 喜欢
否 -> 讨厌$
```

- `选项文本 -> 目标`，目标是标签名或节点索引
- 不写 `->`：选中后进入下一个节点

带属性：

```dvns
@选项
是 -> 喜欢, 设置变量="好感" +1
否 -> 讨厌, 设置变量="好感" -1
也许 -> 喜欢, 条件=好感 >= 5, 否则=讨厌
隐藏 -> 隐藏结局, 条件=好感 >= 10, 解锁CG=结局CG
```

支持的属性：

- `设置变量`：选中后设置变量
- `条件`：**JavaScript** 表达式，为假时该选项默认不显示；如果同时写了 `否则`，则不隐藏，点击后跳转到 `否则` 目标
- `否则`：条件为假时的跳转目标
- `解锁CG`：选中后解锁指定 **CG**
- `样式`：选项按钮的 **CSS**

## 目标

跳转到指定位置。

```dvns
@目标 5
@目标 标签名
@目标 标签名, 章节=第二章
@目标 索引, 章节=第二章
```

- 数字：跳到当前章节的节点索引
- 字符串：跳到当前章节的标签
- 带 `章节`：跳到指定章节

## 标签

给节点设置标签，供 `@目标` 跳转。

```dvns
@标签 喜欢
"Tian": 我喜欢你~$
```

## 条件

根据条件跳转。

```dvns
@条件 好感 >= 10, 真=好结局, 假=坏结局
```

- 第一个参数：**JavaScript** 表达式
- `真`：条件为真时跳转的目标
- `假`：条件为假时跳转的目标

表达式里可以直接用变量名：

```dvns
@条件 金币 > 100 && 等级 >= 5, 真=购买成功, 假=金币不足
```

读嵌套变量用 getVar：

```dvns
@条件 getVar('玩家.血量') === 100, 真=继续, 假=重玩
```

可在对话、选项、路径、标题里使用 `{变量名}`：

```dvns
"Tian": 你好，{name}！
@背景 assets/bg/{场景}.png
@标题 第{章节}章
```


## 自动存档

在当前节点触发自动存档。

```dvns
@自动存档
```

## 自动节点

等待指定秒数后自动推进。

```dvns
@自动节点 1.5
```

## 解锁CG

解锁一张 **CG** 到收藏库。

```dvns
@解锁CG 结局CG, assets/cg/ending.png
```

## 调查

进入调查模式，玩家点击指定区域触发跳转。

```dvns
@调查 光标=pointer, 返回=返回标签
区域 x=100, y=200, 宽=300, 高=200, 目标=抽屉, 贴图=assets/ui/drawer.png
区域 x=500, y=300, 宽=200, 高=200, 目标=窗户
```

- `光标`：**CSS** 光标，如 `pointer`、`crosshair`
- `返回`：点击返回按钮时跳转的目标
- `区域`：可点击区域，多区域写多行

## 跳转HTML

跳转到其他 **HTML** 页面，可传参和传变量。

```dvns
@跳转HTML index.html
@跳转HTML index.html, 参数=page=1
@跳转HTML index.html, 传递变量=name,金币
```

## 逐字显示

控制文本的逐字显示，可在 `js/游戏配置.js` 修改默认设置。`速度`单位为秒，越小越快。

```dvns
@逐字显示 速度=0.02
@逐字显示 false 
// 或 true
```

## 打字音效

逐字显示时播放音效，同样可在 `js/游戏配置.js` 中修改默认设置。

```dvns
@打字音效 assets/se/type.mp3, 音量=0.5, 间隔=3
@打字音效 false 
// 或 true
```

## 快进

控制快进模式。

```dvns
@快进 true
@快进 false
```

## 自定义功能

执行自定义 **JavaScript** 代码。

```dvns
@自定义功能 弹窗('你好')
@自定义功能 console.log('调试')
```

## 动画

给指定元素应用 **CSS** 动画。

```dvns
@动画 对话框=对话框进入动画 0.3s ease
@动画 内容=颤抖 0.5s
@动画 左立绘=淡入 0.3s
```

可设置动画的内容：`左立绘`、`中立绘`、`右立绘`、`背景`、`对话框`、`角色`、`内容`、`头像`。

## 特殊标签

- `<wait=1.5>`：等待 1.5 秒后继续逐字显示

## 注释

以 `//` 开头的行会被忽略。

```dvns
// 这是注释
"Tian": 你好$
```

注释只能整行，不能行尾。
