# 章节概念

章节是使用 Dvnge 制作游戏的基本，它们是在 `chapter/` 文件夹中的文件。引擎支持两种章节文件格式：

- **`.dvns` 文件**：Dvnge 独创的剧本语法，写起来简洁，推荐使用。
- **`.js` 文件**：用 JavaScript 对象数组描述节点，类 Json 语法，适合比较复杂脚本场景。

两种格式可以混用，引擎按 `章节文件列表` 里配置的路径后缀自动识别。

## 使用 dvns 文件

在 `chapter/` 文件夹中创建一个 `序章.dvns` 文件，然后里面写上这样的代码：

```dvns
"Tian": 你好，世界。$
```

之后保存文件，这样就写好了一个基础的对话（现在看不懂为什么这么写不要紧，之后都会详细讲解）。

## 使用 js 文件

在 `chapter/` 文件夹中创建一个 `序章.js` 文件，然后里面写上这样的代码：

```javascript
var 序章 = [
    {
        角色: "Tian",
        内容: "你好，世界。"
    }
];
```

- 变量名要和章节名一致，引擎靠它拿到节点列表。
- 每个元素是一个节点，节点里可以写 `角色`、`内容`、`立绘`、`背景` 等属性。

## 配置章节列表

只创建文件是不起作用的，我们还需要在 `js/游戏配置.js` 中加上所添加的章节路径。

在 `js/游戏配置.js` 文件中找到 `章节文件列表`，然后在末尾添加对应的行。

`.dvns` ：

```javascript
{ 名称: "序章", 路径: "chapter/序章.dvns" }
```

`.js` ：

```javascript
{ 名称: "序章", 路径: "chapter/序章.js" }
```

加上后完整的 `章节文件列表` 代码是这样的：

```javascript
const 章节文件列表 = [
    { 名称: "序章", 路径: "chapter/序章.dvns" },
];
```

这样添加章节的配置就完成了！运行 `game.html` 就可以看到我们写的对话了。
